## Computational level
- **study_focus:** Observational learning; emulation vs. imitation; autism-like traits and social goal inference (confirmatory replication)
- **study_focus_short:** Observational learning
- **learning_mode_description:** - Learning mode: Learning from observing a partner's slot machine choices (without seeing outcomes) about which token is currently valuable, via either goal emulation (Bayesian inference of the partner's goal) or action imitation (repeating the partner's action).   - Learning from:     - Source type (social): other (partner/demonstrator)     - Source content (social): action/policy (partner's slot machine choices)   - Learning about:     - Target type (non-social): world (which token is valuable)     - Target content (non-social): state (world state; identity of the valuable token)
- **task_description:** Same observational learning task as Study 1 with minor design modifications: 96 trials (vs. 84), equalized accuracy for pure imitator and pure emulator to decorrelate task performance from emulation propensity. Participants observe a partner's choices and then make their own slot machine choices.
- **task_paradigm:** Observational learning task
- **players:** Single agent (participant), single partner (pre-recorded demonstrator agent with full information)
- **n_players:** single agent (1)
- **partner_type:** human (recorded)
- **stimuli:** Slot machines with colored token distributions (red, green, blue), video recordings of partner's hand pressing buttons, colored tokens as feedback
- **method:** online / behavioural
- **method_full:** behavioural / online
- **main_result:** - Main Results:   - Emulation propensity negatively correlated with autism-like traits (F1) (r = -0.200, 95% CI [-0.298, -0.098])   - Emulation bias parameter (delta) negatively correlated with F1 (r = -0.156, 95% CI [-0.257, -0.053])   - Emulation group had lower F1 than non-learning group (Cohen's d = 0.597) and imitation group (Cohen's d = 0.448)   - Emulation propensity predicted F1 after controlling for IQ, WM, age, gender (beta = -0.160, eta-p-squared = 0.0240)   - Emulation bias predicted F1 after controlling for all model parameters (beta = -0.106, eta-p-squared = 0.0101)   - F1 predicted emulation propensity after controlling for social anxiety and other psychiatric dimensions (beta = -0.190, eta-p-squared = 0.0283)   - No significant association between arbitration and autism-like traits (r = -0.012 for arbitration propensity; r = -0.018 for eta)   - Fixed mixture model was the best-fitting model (highest model frequency, exceedance probability, lowest AIC)
- **effect_size:** - Emulation propensity ~ F1: r = -0.200, Cohen's d = 0.141 (uncertainty effect) - Emulation bias ~ F1: r = -0.156 - Emulation group vs non-learning group: Cohen's d = 0.597; vs imitation group: Cohen's d = 0.448 - Multiple regression emulation propensity -> F1: beta = -0.160, R-squared = 0.0694, Cohen's f-squared = 0.075 - Specificity regression (controlling psychiatric dimensions): beta = -0.190, eta-p-squared = 0.0283
