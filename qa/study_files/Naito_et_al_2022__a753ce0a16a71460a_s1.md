## Computational level
- **study_focus:** Social learning in collective search; across-task generalization learning; exploration-exploitation in spatially correlated environments
- **study_focus_short:** Social learning in collective search
- **learning_mode_description:** - Learning mode: Learning from a partner's search choices about the common generative rule (spatial correlation) underlying reward landscapes across multiple environments.     - Learning from:       - Source type (social): other (paired partner)         - Source content (social): action/policy (partner's preceding choice location)     - Learning about:       - Target type (non-social): world (environmental structure)         - Target content (non-social): state (generative rule / spatial correlation parameter of reward landscape)
- **task_description:** Participants completed six sessions of a 165-armed bandit task (11x15 grid) with spatially correlated rewards generated from a Gaussian process. - **main_result:** - Pair condition outperformed solo across all sessions (LMM, condition mean = 3.28, 95% CI [1.41, 5.16])   - Session x condition interaction: advantage grew across sessions (mean = 1.21, 95% CI [0.31, 2.06])   - Subjective generative rule parameter closer to true value in pair (median = 1.59) vs solo (median = 1.86) (LMM mean = -0.72, 95% CI [-1.21, -0.25])   - Generative rule parameter correlated within real pairs (Spearman rho = 0.39, P < 0.01) but not other parameters   - Generative rule parameter converged more in real vs shuffled pairs (Mann-Whitney U = 1006.0, P = 0.02)   - Imitation bias follows inverted U-shape: moderate gamma beneficial, extreme detrimental

## Quality
- **sample_size:** N=121 (61 female; mean age 21.4 +/- 0.2 years); solo condition n=47, pair condition n=74 (37 pairs). 3 participants had partial data (only first 3 sessions due to computer failure).
- **population_category:** healthy adults
- **population_age_range:** M=21.4
- **ecological_validity:** Moderate-low. Lab-based grid foraging task with abstract reward landscape. Spatial correlation of rewards is ecologically motivated (analogous to real-world patchy environments), but the grid search space is artificial. Partner information limited to choice location only. No direct communication allowed.
- **eligibility_flag:** 
- **concerns:** Lambda-hat estimated collapsed across all 6 sessions rather than session-by-session (insufficient data for session-specific estimation); no model recovery analysis reported; effect sizes for some key comparisons are Bayesian credible intervals rather than standardized effect sizes; solo condition has smaller n than pair condition (47 vs 74).
- **limitations_reported:** The identity of the critical interaction element in this process remains unknown"; "the amounts or kinds of information exchanged during interaction may be critical"; "the key environmental parameter lambda that generated each search space was fixed to be the same (= 1.5) across the sessions"; "we estimated a participant's subjective understanding about the generative rule by collapsing across all six sessions — this analysis precluded seeing how lambda-hat may have evolved across the six sessions"; "neither parameter estimation converged due to the small number of samples (25 x 3 = 75 trials)"; "introducing other environmental structures will be important to further test the possibility of across-task learning through social interaction
- **limitations_categorized:** limited ecological validity; task simplicity (single fixed generative rule); limited parameter estimation (collapsed across sessions); small trial count per session; limited generalizability (single environmental structure); unclear mechanism of social influence
