## Computational level
- **study_focus:** Imitation learning / observational learning in social reinforcement learning — how observing a demonstrator's choices integrates into a learner's reinforcement learning process.
- **study_focus_short:** Imitation learning / observational learning in social reinforcement learning
- **learning_mode_description:** - Learning mode: Learning from observing a demonstrator's choices about stimulus-reward contingencies (imitation in reinforcement learning)   - Learning from:     - Source type (social): other (demonstrator)     - Source content (social): action/policy (demonstrator's choices on same stimulus pair)   - Learning about:     - Target type (non-social): world (stimulus-reward associations)     - Target content (non-social): outcome (which stimulus is reward-maximizing)
- **task_description:** Participants repeatedly chose between two abstract visual stimuli to win or lose a point (probabilistic instrumental learning). In observational conditions, the learner also observed a demonstrator's choices (but not outcomes) on the same stimuli, interleaved with their own private choices; demonstrator skill (skilled vs. unskilled) was manipulated within-subject (Exp 1) or between-subjects (Exp 2, Exp 3).
- **task_paradigm:** Probabilistic reward learning
- **players:** Single agent (participant/learner), single demonstrator (computer-controlled in Exp 1-2; recorded real participant in Exp 3). Exp 3 additionally manipulated whether the demonstrator's IQ was visible.
- **n_players:** single agent (1)
- **partner_type:** unclear
- **stimuli:** Abstract visual symbols (pairs), binary reward feedback (win/lose a point), demonstrator's choice highlighted on the same symbol pair; question mark replacing demonstrator's outcome.
- **method:** behavioural
- **method_full:** Behavioural (all three experiments)

## Algorithmic level
- **winning_model:** Value Shaping (VS2): symmetric RW with imitation as pseudo-reward. $Q(d) \leftarrow Q(d) + \alpha_i \cdot [1 - Q(d)]$ and $Q(\bar{d}) \leftarrow Q(\bar{d}) + \alpha_i \cdot [-1 - Q(\bar{d})]$; private learning: $Q(c) \leftarrow Q(c) + \alpha_p \cdot [r - Q(c)]$ with symmetric counterfactual update; softmax with choice autocorrelation $\kappa$. Parameters: $\alpha_p$ (private learning rate), $\alpha_i$ (imitation learning rate) [S], $\beta$ (inverse temperature), $\kappa$ (choice autocorrelation). Best variant also tested: meta-VS with dynamic $\alpha_i$ updated via auxiliary learning rate $\alpha_m$.
- **model_family:** Rescorla-Wagner
- **model_class:** PE learning
- **all_models_tested:** [   {"name": "RW (RW2, symmetric update)", "family": "Rescorla-Wagner", "n_params": 3, "metric": "AIC"},   {"name": "DB (DB6, symmetric value update + accumulation)", "family": "Decision biasing (Rescorla-Wagner + policy bias)", "n_params": 4, "metric": "AIC"},   {"name": "MB (MB9, symmetric value update for both demonstrator model and action bias)", "family": "Model-based imitation (inverse RL + action bias)", "n_params": 4, "metric": "AIC"},   {"name": "VS (VS2, symmetric value shaping)", "family": "Rescorla-Wagner with value shaping", "n_params": 4, "metric": "AIC"},   {"name": "meta-VS (dynamic imitation rate)", "family": "Rescorla-Wagner with meta-learning value shaping", "n_params": 4, "metric": "AIC"} ]  Note: 19 total model variants were compared in intermediate comparisons (2 RW, 6 DB, 9 MB, 2 VS) before the final 4-model comparison. The meta-VS was compared against VS in a separate step.
- **model_mb_mf:** MF (model-free; explicitly stated: "imitation is instantiated as a model-free learning process, as it does not require an explicit model of the Demonstrator")
- **model_params:** - $\alpha_p$: private reward learning rate (Exp 1: significantly higher than $\alpha_i$; Exp 2 SD: significantly higher than $\alpha_i$; exact mean fitted values not reported in main text) - $\alpha_i$: imitation learning rate [S] (higher for SD than UD condition; exact mean fitted values not reported in main text) - $\beta$: softmax inverse temperature - $\kappa$: choice autocorrelation parameter - For meta-VS: $\alpha_m$: auxiliary meta-learning rate for dynamically updating $\alpha_i$ [S]
