## Computational level
- **study_focus:** Social structure learning — learning latent social group boundaries from observed political preferences of novel agents, distinguishing dyadic similarity from latent group structure inference.
- **study_focus_short:** Social structure learning
- **learning_mode_description:** - Learning mode: Learning latent social group structure from agents' political preference choices to infer coalition membership (ally vs. non-ally)   - Learning from:     - Source type (social): other (three novel agents: A, B, C) + self     - Source content (social): action/policy (political issue stances — agree/disagree choices)   - Learning about:     - Target type (social): group (latent coalition structure among self and agents)     - Target content (social): state (mental state; group membership / coalition boundaries)
- **task_description:** Participants reported their own political stance on an issue, then guessed and received feedback on three novel agents' stances across eight issues per run. After learning, participants chose to align with either Agent A or Agent B on an unknown "mystery" political issue (ally-choice trial).
- **task_paradigm:** Social network learning
- **players:** Single agent (participant), multi-target (3 novel agents per run; 18 agents total across 6 runs)
- **n_players:** multi-target (3+)
- **partner_type:** human (live)
- **stimuli:** Political issue text prompts, face photographs (from Chicago Face Database), binary yes/no feedback on agents' stances
- **method:** fMRI
- **method_full:** fMRI
- **main_result:** - Agent C's agreement with participant predicted choosing Agent B on ally-choice trial above and beyond Agent B's own agreement (b = 1.322, Wald's z = 2.633, 95% CI [0.371, 2.349]) - Agent B's agreement predicted ally-choice (b = 2.325, Wald's z = 4.099, 95% CI [1.284, 3.519]) - Interaction between Agent B and Agent C agreement (b = -0.307, Wald's z = -2.588, 95% CI [-0.550, -0.082]) - Latent structure model parametric modulator: rAI cluster (PXP = 82.34% for latent structure model in rAI; BOR = 0.190) - Dyadic similarity parametric modulator: pgACC cluster (PXP = 51.58% for latent structure model in pgACC; no model specificity, BOR = 0.675) - rAI signal improved prediction of ally-choice behavior for latent structure model (chi-squared(1) = 5.312, p = 0.021) - pgACC signal did not improve prediction of ally-choice behavior for dyadic similarity model (chi-squared(1) = 1.526, p = 0.217)
- **effect_size:** - Logistic regression: Agent B agreement b = 2.325; Agent C agreement b = 1.322; interaction b = -0.307 - Bayesian model selection in rAI: PXP = 82.34% (latent structure), BOR = 0.190 - Likelihood ratio test for rAI signal predicting behavior: chi-squared(1) = 5.312

## Quality
- **sample_size:** N = 42 (fMRI; 32 female, M_age = 22.07, SD = 4.82); recruited from N = 333 behavioral participants (for behavioral pre-screening); 61 initially recruited for fMRI, 19 excluded (2 withdrew, 2 computer crash, 5 fell asleep, 8 excessive head motion, 1 guessed hypothesis, 1 missing responses)
- **population_category:** healthy adults
- **population_age_range:** 
- **ecological_validity:** Moderate — uses real political issues (from ISideWith.com) as stimuli, providing some ecological grounding; however, agents are fictional with randomized (non-ideologically coherent) preference profiles, interaction is entirely one-directional (no real social exchange), and the binary agree/disagree format is simplified compared to real social group formation.
- **eligibility_flag:** 
- **concerns:** - High correlations between parametric modulators (dyadic similarity and latent structure r = 0.86; dyadic similarity and feature similarity r = 0.96) raise collinearity concerns, though VIF for the key comparison (dyadic vs. latent) was 5.06 - Models were run in separate GLMs rather than competing within the same GLM (acknowledged by authors: "No clusters survived correction when all three models were included as parametric modulators") - No free parameters were fit to behavior for any model — the "winning model" was selected based on neural data fit (PXP in rAI), not behavioral model comparison - Agent preference profiles were not ideologically coherent (random mixture of left/right stances) - Large exclusion rate (19/61 = 31%)
- **limitations_reported:** Our sample size here may have been too small to detect a difference" (regarding behavioral effect in N=333 sample); "including random slopes to account for subject-level effects resulted in a singular fit of the model (i.e., overfitting), so we removed them"; the two behavioral conditions "may have been too obvious for a version of the task that was not self-paced"; agent preference profiles included mixture of partisan left and right beliefs (not ideologically coherent)
- **limitations_categorized:** Sample size; model overfitting (singular fit with random slopes); task design limitations (timing constraints); limited ecological validity (non-coherent agent profiles)
