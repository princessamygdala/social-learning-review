## Computational level
- **study_focus:** Prosocial learning — how intranasal oxytocin (dose-response) modulates reinforcement learning when learning to benefit others vs. oneself.
- **study_focus_short:** Prosocial learning
- **learning_mode_description:** - Learning mode: Learning from reward feedback to benefit self or a stranger   - Learning from:     - Source type (non-social): self     - Source content (non-social): outcome (binary reward feedback — 100 points or 0 points)   - Learning about:     - Target type (social): other (stranger / confederate) [prosocial condition]     - Target type (non-social): self [self-oriented condition]     - Target content (non-social): action/policy (which symbol maximises reward probability)
- **task_description:** In a probabilistic reinforcement learning task, participants chose between two abstract symbols (75% vs 25% reward probability) across blocks where points were earned either for themselves (self-oriented) or for a stranger/confederate (prosocial), with feedback on each trial indicating whether the choice was rewarded. This was embedded in a double-blind, placebo-controlled, within-subjects, dose-response design with three doses of intranasal oxytocin (9, 18, 36 IU) and placebo.
- **task_paradigm:** Probabilistic reward learning
- **players:** Single agent (participant), single-target (1 confederate/stranger)
- **n_players:** single agent (1)
- **partner_type:** confederate
- **stimuli:** Abstract symbols (Agathodaimon font letters), binary feedback (win 100 points / win 0 points)
- **method:** fMRI / pharmacological
- **method_full:** fMRI (pharmacological: intranasal oxytocin dose-response)
- **main_result:** - Main Results:   - Self-bias in learning: participants more likely to choose high-reward option for self than other (χ²(1) = 19.459, p_boot < .001)   - Three-way interaction of learning condition × block × treatment (χ²(9) = 23.382, p_boot = .005); low dose prevented prosocial performance decline over blocks   - Winning model M3 (separate α per condition, shared β): iBIC = 11,079.22, exceedance probability = 0.99, R² = 0.69   - Higher learning rates for self-oriented vs prosocial learning (χ²(1) = 5.773, p_boot = .016)   - sgACC specifically encoded PEs during prosocial but not self-oriented learning (prosocial PE parameter estimate = 0.500, 95% CI [0.364, 0.636])   - Learning condition × treatment interaction on sgACC PE encoding (χ²(3) = 16.431, p_boot = .004) — inverted-U dose-response in prosocial condition   - Learning condition × treatment interaction on midbrain PE encoding (χ²(3) = 11.058, p_boot = .011)   - PEs encoded in midbrain–sgACC functional coupling specifically during prosocial learning (χ²(1) = 27.132, p_boot < .001)   - Learning condition × treatment interaction on midbrain–sgACC PPI (χ²(3) = 15.727, p_boot < .001)   - Prosocial PE encoding in sgACC correlated with prosocial learning rate (r(22) = 0.664, p_boot = .001)   - Midbrain–sgACC functional coupling during prosocial PE correlated with prosocial learning rate (r(22) = 0.859, p_boot < .001)   - DCM: Low dose increased excitatory midbrain-to-sgACC forward transmission (expected value = 0.152, Pp = 0.932); High dose decreased midbrain intrinsic connectivity (expected value = −0.034, Pp = 0.901)   - Excitatory midbrain-to-sgACC connection strength correlated with prosocial learning rate (expected value = 0.120, Pp = 0.995)

## Quality
- **sample_size:** N = 24 healthy males (1 excluded from fMRI for excessive motion; N = 23 for fMRI analyses); mean age 23.8 years (SD = 3.94, range 20–34); within-subjects design (4 sessions per participant)
- **population_category:** healthy adults
- **population_age_range:** 20–34
- **ecological_validity:** Limited. No face-to-face interaction between participant and confederate; anonymous decisions; abstract symbols rather than naturalistic social stimuli; male-only sample of predominantly white Caucasian ethnicity; laboratory fMRI setting. Authors acknowledge task lacks interactive/reciprocal component of real-world prosociality.
- **eligibility_flag:** 
- **concerns:** - Very small sample (N = 24, within-subjects) even with power analysis justification; may be underpowered for dose-response interaction effects - Male-only sample limits generalizability - Post-hoc pairwise comparisons for the 3-way behavioral interaction did not survive correction — interpretation relies on visual inspection of plots - Deception paradigm (confederate presented as real participant) - Mean fitted parameter values for winning model not explicitly reported as summary statistics - No peak MNI coordinates reported for any analysis (ROI-based with anatomical masks; whole-brain supplementary figures lack coordinate tables) - BOLD fMRI cannot directly test dopamine hypothesis
- **limitations_reported:** Findings should not be readily extrapolated to women given known sexual dimorphism in the oxytocin system; dopamine system was not pharmacologically manipulated so the oxytocin-dopamine interaction hypothesis requires further validation; BOLD fMRI does not allow direct testing of phasic vs tonic dopamine release hypothesis; intranasal oxytocin was administered using the PARI SINUS nebuliser which may complicate comparisons with standard nasal spray doses; task did not include interaction/reciprocity component so findings may not generalise to face-to-face prosocial scenarios; cannot determine whether oxytocin reaches the brain directly or acts through peripheral mechanisms
- **limitations_categorized:** Limited generalizability (male-only sample); limited ecological validity (no social interaction); pharmacological specificity (no dopamine manipulation); measurement limitation (BOLD cannot measure dopamine directly); device-specific dosing (nebuliser vs spray); task simplicity (no reciprocity/reputation component); mechanistic uncertainty (central vs peripheral oxytocin action)  ---  ### WC GUIDELINES  1. **Design a good experiment**: Yes — task specifically designed to dissociate self-oriented from prosocial learning (Lockwood et al., 2016 paradigm) 2. **Design good models**: Yes — 5 competing models including null model, varying in parameter structure 3. **Simulate, simulate, simulate**: Yes — model identifiability analysis with 10 simulated datasets of 100 participants each (Supplementary Fig. S6) 4. **Fit the parameters**: Yes — iterative MAP fitting procedure 5. **Check parameter recovery**: Yes — parameter recovery on 100 simulated participants; correlations between true and recovered: α_self r = 0.725, α_prosocial r = 0.775, β r = 0.797 (Supplementary Fig. S7) 6. **Check model recovery**: Yes — confusion matrix of exceedance probability and best-model-selection across 10 simulations (Supplementary Fig. S6); M3 clearly identifiable 7. **Fit real data and compare models**: Yes — iBIC, exceedance probability, and R² reported; M3 won on all three criteria 8. **Validate the winning model**: Yes — simulated choices from MAP estimates predicted actual participant choices (R² = 0.224–0.841; Supplementary Table S2); also verified M3 won within each treatment level separately (Supplementary Fig. S5/Table S1) 9. **Analyze the winning model**: Yes — learning rate parameters analyzed as function of condition and treatment; used as neural correlates; PE trajectories used as fMRI parametric modulators 10. **Report results transparently**: No — no mention of shared data or code
