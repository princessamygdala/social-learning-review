## Computational level
- **study_focus:** Associative value learning and value-driven attentional detection of neutral faces; age-related differences in learning rate sensitivity and visual search efficiency.
- **study_focus_short:** Associative value learning and value-driven attentional detection of neutral
- **learning_mode_description:** - Learning mode: Learning from reward/punishment feedback outcomes about the emotional value associated with neutral faces.   - Learning from:     - Source type (non-social): self     - Source content (non-social): outcome (monetary reward/punishment feedback)   - Learning about:     - Target type (social): other (neutral face stimuli representing other individuals)     - Target content (social): stimulus (emotional value associated with neutral faces)
- **task_description:** Participants chose one face from a pair of neutral faces to maximize earnings across 300 trials, receiving probabilistic monetary reward (+20 yen), punishment (−20 yen), or zero feedback. Subsequently, in a visual search task (192 trials), participants detected whether one face differed from three distractors, where targets were the previously learned value-associated faces.
- **task_paradigm:** Probabilistic reward learning
- **players:** Single agent (participant), multi-target (6 neutral face stimuli in 3 pairs)
- **n_players:** multi-target (3+)
- **partner_type:** human (recorded)
- **stimuli:** Grayscale neutral male face photographs, monetary feedback (reward/punishment/zero)
- **method:** behavioural
- **method_full:** Behavioural
- **main_result:** - Younger participants had higher learning rates than older participants for both reward (group difference = 0.04, 95% CI [0.02, 0.07]) and punishment (group difference = 0.10, 95% CI [0.04, 0.16]) - Younger participants showed higher drift rates (v) than older participants across all conditions (v_reward group diff = 0.35, 95% CI [0.05, 0.66]; v_punishment group diff = 0.49, 95% CI [0.24, 0.74]; v_zero group diff = 0.32, 95% CI [0.08, 0.57]) - Shorter non-decision time (t0) in younger vs. older participants (group diff = −0.15, 95% CI [−0.16, −0.13]) - In younger participants only, reward learning rate correlated with drift rate for reward-associated faces (Spearman's r = 0.38, p = 0.04) - No cross-model correlations in older participants (|r|s < 0.32, ps > 0.10) - Main effect of learning condition on associative learning (F(2, 110) = 49.61, p < .001, η²_G = 0.32) - Age × learning condition interaction (F(7, 43) = 7.43, p = 0.001, η²_G = 0.07)
