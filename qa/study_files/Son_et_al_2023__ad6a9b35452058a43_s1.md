## Computational level
- **study_focus:** Social network learning; social link prediction via multistep relational abstraction. How people learn and represent social network structure from observations of pairwise relationships, and how these representations support inferences about unobserved relationships (friendship, trust, advice-giving).
- **study_focus_short:** Social network learning · social link prediction via multistep relational abstraction
- **learning_mode_description:** - Learning mode: Learning from observed pairwise social relationships to infer unobserved social network structure   - Learning from:     - Source type (social): other (network members)     - Source content (social): stimulus (observed pairwise interactions/friendships)   - Learning about:     - Target type (social): group (social network structure)     - Target content (social): state (relational structure; who is connected to whom, including unobserved links)
- **task_description:** Participants observed pairwise friendships in an artificial social network (via random walks or paired associates) and then reported which pairs they believed were friends, including unobserved pairs. In a second phase, participants also inferred how much network members would trust each other in an economic trust game.
- **task_paradigm:** Trust game
- **players:** Single agent (participant), multi-target (13 network members in Studies 1-2; 26 in Study 3; 21 real-world managers in Study 4)
- **n_players:** network (5+)
- **partner_type:** none
- **stimuli:** Faces from Chicago Face Database (Studies 1-2), schematic network diagrams (Study 3), names of real-world managers (Study 4), binary friendship/advice-giving relationships
- **method:** online / behavioural
- **method_full:** behavioural / online
- **main_result:** - Main Results:   - Multistep relational abstraction (Successor Representation) explains schema-like network representations better than triad or community schemas at all values of gamma (BIC comparison; Study 1 simulation + Study 2)   - Group-level use of SR in Random Walks sample (mean beta = 1.74, t(59) = 6.49, 95% CI = [1.20, 2.27])   - Group-level use of SR in Paired Associates sample (mean beta = 1.55, t(27) = 6.44, 95% CI = [1.05, 2.04])   - Greater memory abstraction predicts greater trust inference across network distances (beta = 15.20, t = 5.50, 95% CI = [9.52, 20.87])   - SR with gamma = 0.7 best fits real-world network representations (BIC = 8,780.27; Study 4)   - SR centrality correlates with betweenness centrality (Spearman rho = 0.89)   - SR predicts perceived centrality (mean Spearman rho = 0.43)   - Model correctly predicts individual-level centrality perceptions (18/21 for one pair, 15/21 for another; exact binomial tests P < 0.001 and P = 0.039)

## Quality
- **sample_size:** Study 1: simulation only. Study 2: N = 60 (Random Walks; 41 in-lab, 19 online) + N = 28 (Paired Associates; ages 18-31, mean 22.29). Study 3: N = 180 (reanalysis of Sehl et al., 2022). Study 4: N = 21 managers (reanalysis of Krackhardt, 1987).
- **population_category:** healthy adults
- **population_age_range:** 18–31
- **ecological_validity:** Studies 1-3 use artificial social networks with face stimuli or schematics, limiting ecological validity. Study 4 uses a real-world workplace advice network (21 managers at a technology manufacturing company), providing higher ecological validity but with no control over observational history. The paper itself notes that real-world networks incorporate many uncontrolled sources of knowledge (informal friendships, hierarchy) not provided to the model.
- **eligibility_flag:** 
- **concerns:** - Study 1 is a simulation; no human data. - Studies 3 and 4 are reanalyses of previously published datasets (Sehl et al., 2022; Krackhardt, 1987), not original data collection. - Random Walks sample (Study 2) was originally collected to pilot unrelated experiments and sample size was unplanned. - No parameter recovery or model recovery analyses reported. - The SR model and schema models differ in flexibility (SR has free gamma), making BIC comparisons not fully apples-to-apples for fixed-gamma analyses. - No formal model comparison metric (e.g., BMS exceedance probability) for the individual-level computational models; PPC used instead. - Real-world network study (Study 4) requires assumptions about managers' observational history that cannot be verified.
- **limitations_reported:** The SR performs less well for the real-world social network compared to laboratory experiments, likely because real-world networks incorporate other uncontrolled sources of knowledge; memory decay or forgetting may affect fidelity of learned SR in real-world settings; the composition of real-world networks is dynamic and the model assumes a fixed set of individuals; it remains unknown how consciously aware people are of the knowledge structures they build; additional mechanisms may be needed for updating the state space in continually evolving networks.
- **limitations_categorized:** limited ecological validity; memory and forgetting not modeled; static network assumption; limited generalizability to dynamic networks; no neural implementation tested; implicit vs. explicit knowledge not distinguished
