## Computational level
- **study_focus:** Perceptual prediction error learning — feature-specific precision-weighted prediction errors (pwPEs) for color and emotional expression of faces in a roving visual mismatch paradigm. The study tests whether identical stimuli elicit distinct pwPEs when different feature-specific predictions (color vs. emotion) are violated, even without attention.
- **study_focus_short:** Perceptual prediction error learning
- **learning_mode_description:** - Learning mode: Learning statistical regularities in stimulus sequences to generate feature-specific predictions about face color and emotional expression   - Learning from:     - Source type (non-social): world       - Stimulus sequence (roving standard paradigm of face stimuli)     - Source content (non-social): stimulus       - Binary stimulus features: color (red/green) and emotional expression (happy/fearful)   - Learning about:     - Target type (non-social): world       - Statistical regularities in environment (stimulus transition probabilities)     - Target content (non-social): state (world state)       - Predicted probability of next stimulus feature (color, emotion)
- **task_description:** Participants viewed sequences of face stimuli (varying in color: red/green and emotion: happy/fearful) presented in peripheral quadrants while performing an unrelated central fixation cross change-detection task. Face stimuli followed a roving standard paradigm where each stimulus type repeated 5–9 times before transitioning to another type.
- **task_paradigm:** Visual mismatch (oddball) task
- **players:** Single agent (participant), no social interaction partner. Faces are stimuli, not interactive agents.
- **n_players:** single agent (1)
- **partner_type:** human (recorded)
- **stimuli:** Colored face photographs (Radboud Faces Database) — red or green tinted, happy or fearful expressions; fixation cross change-detection task at center.
- **method:** fMRI
- **method_full:** fMRI (with eye-tracking)
- **main_result:** - Color pwPE activations in bilateral fusiform gyrus (L fusiform peak: −30, −58, −14; 326 voxels; R fusiform peak: 32, −46, −20; 212 voxels) — whole-brain FWE-corrected p < 0.05 at cluster level - Emotion pwPE activations in bilateral cerebellum, cuneus, lingual gyrus, precuneus, thalamus, R supramarginal gyrus, R posterior medial frontal cortex (largest cluster: R cuneus peak 10, −88, 26; 1417 voxels) - Emotion predictions activated bilateral fusiform gyri and R superior/middle temporal gyrus - No significant interaction between color and emotion pwPEs - Change detection (CD) regressors failed to produce significant group-level results for emotion, while HGF-based pwPE regressors did — suggesting pwPE model captures more consistent cross-subject representations
- **effect_size:** No standardized effect sizes reported; only cluster statistics (flagged in concerns)

## Quality
- **sample_size:** N = 35 (from initial N = 39; 1 excluded for incomplete data, 3 lost partial data during transfer); mean age = 23.06 years, SD = 3.02 years, 15 females. All right-handed, healthy, normal/corrected vision.
- **population_category:** healthy adults
- **population_age_range:** M=23.06
- **ecological_validity:** Low. Laboratory paradigm with abstract roving standard sequences of colored face photographs. Faces are static images presented briefly (200ms) in peripheral vision while participants perform an unrelated fixation task. No social interaction. The automatic perceptual processing is ecologically relevant to the extent that it models continuous environmental monitoring, but the task context is highly artificial.
- **eligibility_flag:** LOW confidence that this qualifies as social learning — strong concern this is perceptual inference, not social learning
- **concerns:** - No formal model comparison metric (BIC/AIC/BMS) — the HGF was selected over CD based on group-level significance of GLM regressors, not standard model comparison - HGF parameters were not fitted to individual participants — Bayes-optimal observer simulation only - No standardized effect sizes reported (no Cohen's d, r, β, etc.) - Authors acknowledge they cannot rule out neural adaptation/fatigue as alternative to predictive coding - The paper uses emotional faces but studies perceptual prediction, not social cognition or social learning - No behavioral data from the face processing itself (only fixation cross task RT and hit rate)
- **limitations_reported:** The method (fMRI) does not allow direct statements about neuronal implementation (e.g., neuronal fatigue, suppressive effects, network effects); based on current analysis it is not possible to reject some form of adaptation as a potential mechanism as opposed to hierarchical Bayesian inference; the study only considered interaction between color and emotion PEs at the GLM level, not at the level of the HGF perceptual model; investigating interactions at the HGF level would require establishing a novel HGF that incorporates interactions between hidden beliefs
- **limitations_categorized:** limited mechanistic inference from fMRI; adaptation confound; incomplete model specification (no cross-feature HGF interaction); no individual parameter fitting; no formal model comparison
