## Computational level
- **study_focus:** Observational learning; feedback learning; reward processing in OCD
- **study_focus_short:** Observational learning; feedback learning; reward processing in OCD
- **learning_mode_description:** Learning from own and observed (vicarious) probabilistic feedback about stimulus-reward contingencies
- **task_description:** Participants completed active and observational versions of a probabilistic feedback learning task (Frank et al., 2004). In each trial, one of three stimulus pairs (with opposing reward probabilities: 80/20, 70/30, 60/40) was presented; in the active version participants chose a stimulus and received win (+20 points) or loss (-10 points) feedback, while in the observational version they watched a previous participant's yoked choices and outcomes.
- **task_paradigm:** Observational learning task
- **players:** Single agent (participant), single observed agent (previous participant, yoked design); three diagnostic groups: OCD (n=27), SAD (n=29), HC (n=27)
- **n_players:** network (5+)
- **partner_type:** none
- **stimuli:** Modified Japanese characters (abstract), binary feedback (win +20 / loss -10 points)
- **method:** EEG
- **method_full:** EEG
- **main_result:** - OCD patients showed generally impaired task performance across active and observational learning compared to HCs (b = 0.73, 95% CI = 0.15 to 1.31, z = 2.47, p = .014)   - OCD patients showed increased choice shifting (indecisiveness) compared to HCs (b = -0.47, z = -2.48, p = .013)   - FRN amplitudes generally attenuated (more positive) in OCD vs. HCs (b = -2.87, t = -4.60, p = .012)   - Enhanced FRN valence coding (loss-win) for active vs. observational learning in OCD vs. HCs (b = 2.10, t = 2.61, p = .011), driven by more positive FRN for wins in OCD (b = -4.55, t = -3.23, p = .004)   - FRN coded both positive PE (b = 4.33, t = 3.14, p = .003) and negative PE (b = -3.16, t = -3.43, p = .002) during active but not observational learning   - ERN/CRN amplitudes did not differ between OCD and HCs   - Model-based ΔQ predicted ERN amplitudes (b = 0.63, t = 2.22, p = .034)   - Adding SPE as predictor increased variance explained (conditional R^2 from 0.225 to 0.280, ΔBIC = 1520)
- **effect_size:** - Task performance OCD vs. HC: b = 0.73 (95% CI = 0.15 to 1.31)   - Choice shifting OCD vs. HC: b = -0.47 (95% CI = -0.85 to -0.10)   - FRN attenuation OCD vs. HC: b = -2.87 (95% CI = -5.11 to -0.64)   - FRN valence coding agency interaction OCD vs. HC: b = 2.10 (95% CI = 0.50 to 3.70)   - FRN win amplitude OCD vs. HC (active): b = -4.55 (95% CI = -7.36 to -1.74)   - Model-based FRN positive PE (active): b = 4.33 (95% CI = 1.17 to 7.50)   - Model-based FRN negative PE (active): b = -3.16 (95% CI = -5.27 to -1.04)   - ΔQ on ERN: b = 0.63 (95% CI = 0.05 to 1.22)

- **concerns:** (1) Supplement not accessible — model comparison details, parameter recovery, model validation, and fitted parameter values are all reportedly in the supplement but could not be verified. (2) The computational modeling is described as "exploratory" — the primary analyses are model-free (G)LMMs on behavioral and ERP data.
