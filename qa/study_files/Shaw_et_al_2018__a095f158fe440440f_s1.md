## Computational level
- **study_focus:** Cooperation learning / reciprocity learning — how dyadic partners learn to reciprocate (positively or negatively) across iterated economic exchanges.
- **study_focus_short:** Cooperation learning / reciprocity learning
- **learning_mode_description:** - Learning mode: Learning from the interaction partner's prior economic choices about how to reciprocate (adapt offers/acceptances) to maximise own payoff.   - Learning from:     - Source type (social): other (interaction partner)       - If joint: not joint     - Source content (social): action/policy (partner's prior offers or accept/reject decisions)       - If joint: not joint   - Learning about:     - Target type (social): other (interaction partner)       - If joint: not joint     - Target content (social): state (mental state; partner's fairness/cooperativeness, emotional state θ)       - If joint: not joint
- **task_description:** Pairs of male participants played a 120-round iterated Ultimatum Game while undergoing dual-fMRI; on each round, the Proposer chose between two divisions of 100 CZK and the Responder accepted or rejected the offer, with both players seeing the full choice set and outcome. - **players:** Multi-agent (dyad), asymmetric (Proposer and Responder roles fixed throughout); 19 dyads (38 participants).

- **partner_type:** human (live)
- **stimuli:** Two-option monetary divisions of 100 CZK (10 choice sets), binary accept/reject feedback, colour-based control condition.

- **main_result:** - Reciprocity model predicted Proposer choices on 73.46% of rounds (AIC = 2345.5; BIC = 2454.4; LL = −1153.7) and Responder choices on 85.57% of rounds (AIC = 1272.2; BIC = 1381.1; LL = −617.1) - Proposer α (reciprocity) was lower than Responder α (0.06 vs. 0.41; Z[18] = 5.04) - Proposer α correlated negatively with proportion of maximally selfish offers in PR (ρ = −0.78) and PP (ρ = −0.88) - Reciprocity model outperformed self-regarding model (α = 0 for both) for Proposers (LR L[19] = −1037.2) and Responders (L[19] = −1553.0) - Reciprocity model outperformed RL model on AIC and BIC (RL Proposers: AIC = 2866.2, BIC = 2883.4; RL Responders: AIC = 1922.74, BIC = 1939.9) - RTs greater for Proposers vs. Responders (ηp² = 0.57) and PR vs. PP (ηp² = 0.27) - IDC in aMCC during PR correlated with Proposer reciprocity (ρ = 0.65) - Greater inter-brain alignment (IDC) in AI and aMCC during PR > PP condition (t-test, cluster-level FWE < 0.05)

However, role assignment was fixed (no role switching), interactions were restricted to binary economic choices, and only male-male dyads were tested, limiting generalizability.  ---  ### 7. ELIGIBILITY FLAG
- **eligibility_flag:** FLAG — borderline learning-vs-decision-making. The reciprocity model is a utility/expected utility model rather than a trial-by-trial learning model (no explicit learning rate or value update rule). The Proposer's memory parameter tracks prior Responder behaviour, providing an adaptive element, but this is closer to statistical estimation of opponent behaviour than standard computational learning. The RL model was tested but lost. Include but flag.
- **concerns:** - The reciprocity model is a utility-maximisation framework from behavioural economics, not a standard computational learning model — it estimates static parameters (α, x₀) rather than trial-by-trial value updates. The "learning" is implicit in the memory parameter M. - Only male-male dyads tested; no female or mixed-sex dyads. - Roles (Proposer/Responder) were fixed, limiting generalizability about reciprocity. - No fair-allocation condition included as a baseline. - IDC analysis is a crude measure (correlating entire concatenated rounds) with no directionality information. - Sample size modest (19 dyads) for a hyperscanning study. - No explicit parameter recovery or model simulation reported.  ---  ### 9. LIMITATIONS (from paper)
