## Computational level
- **study_focus:** Observational threat learning; social transmission of threat via brain-to-brain coupling modulated by social status
- **study_focus_short:** Observational threat learning
- **learning_mode_description:** - Learning mode: Observational threat learning — observer learns threat value of stimuli by watching demonstrator's defensive responses   - Learning from:     - Source type (social): other (demonstrator)     - Source content (social): action/policy (defensive responses/reactions to CS-US pairings)   - Learning about:     - Target type (non-social): world (stimulus-threat contingency)     - Target content (non-social): stimulus (CS+ predicts threat/shock)
- **task_description:** Observers (N=60) watched pre-recorded videos of demonstrators undergoing Pavlovian threat conditioning (CS+ paired with electrical nerve stimulation at 62.5% reinforcement rate) in an MEG scanner; after observational learning, observers completed a direct test (CS+/CS- presented without demonstrator) to assess acquired threat associations. Social status was manipulated via a math competition task before observational learning (half observers believed demonstrator was higher-status, half lower-status).
- **task_paradigm:** Observational learning task
- **players:** Single agent (observer), dyadic (demonstrator-observer; demonstrator pre-recorded). 3 demonstrators each paired with ~20 observers (60 dyads total, 55 after exclusions).
- **n_players:** dyadic (2)
- **partner_type:** human (live)
- **stimuli:** White geometric shapes (CS+, CS-), video recordings of demonstrators' defensive responses, electrical nerve stimulation (US to demonstrator), SCR and pupillometry as outcome measures.
- **method:** MEG / hyperscanning / behavioural
- **method_full:** MEG (sequential hyperscanning), behavioural (SCR, pupillometry, eye-tracking), computational modeling
- **main_result:** - Main Results:   - Observers showed successful threat learning: higher SCR for CS+ vs CS- (β = 0.39, SE = 0.07, t = 5.97)   - Pupil dilation CS+ > CS- (β = 0.45, SE = 0.09, t = 4.85)   - Computational modeling: CS type main effect on initial value V₀ (β = 0.14, SE = 0.002, t = 73.93); social status effect on V₀ (β = 0.03, SE = 0.01, t = 4.27); CS × status interaction on V₀ (β = −0.04, SE = 0.003, t = −15.76)   - Learning rate α: CS type main effect (β = 0.10, SE = 0.005, t = 19.76); social status effect (β = −0.08, SE = 0.01, t = −9.34); CS × status interaction (β = −0.20, SE = 0.01, t = −27.90)   - BtBC (delta band, sensor level): CS+ > CS- in LS group (β = −0.61, SE = 0.13, t = −4.83)   - BtBC (source level): CS+ > CS- main effect (β = 0.13, SE = 0.02, t = 5.46)   - NMF cluster 1 BtBC in CS+_LS predicted differential SCR (r = 0.44) and differential learning rate (r = 0.47)   - Source-level BtBC at lINS-rINS, lvmPFC-rINS, rvmPFC-rINS, lDLPFC-rINS predicted differential pupil response (all r > 0.56)   - Time-varying SVR: BtBC predicted learning outcome after ~4.7s post CS onset (r > 0.49, MAE < 0.28), only in LS group   - Eye-to-eye coupling CS+ > CS- (β = 0.54, SE = 0.15, t = 3.83)  ---  ### 3. ## Quality
- **sample_size:** N = 60 observers (37 females, aged 27 ± 5.07; 5 excluded for signal quality/scanner malfunction, final N = 55); N = 3 demonstrators (2 females, aged 28 ± 2.89). 55 demonstrator-observer dyads total; 27 HS group, 28 LS group.
- **population_category:** healthy adults
- **population_age_range:** 
- **ecological_validity:** Moderate. Uses pre-recorded videos of real (naïve, non-actor) demonstrators, enhancing ecological validity over confederate paradigms. However, sequential scanning means no real-time interaction; social status manipulated via artificial math competition; demonstrator-observer never interact directly. Authors acknowledge math competition may not capture all dimensions of social status.
- **eligibility_flag:** 
- **concerns:** - Only 3 demonstrators for 60 observers — limited generalizability of demonstrator effects (though controlled for statistically) - No a priori power analysis - Social status manipulation via math competition may not generalize to other status dimensions - BtBC from sequential (not simultaneous) scanning — argues for information transfer but is correlational - SVR prediction analyses exploratory in nature - Model comparison details sparse — winning model stated but formal comparison metrics (e.g., LOOIC values, exceedance probabilities) not reported in text
- **limitations_reported:** Small number of demonstrators may limit generalizability; social status manipulated via math competition task which may not represent all forms of social status; sequential scanning limits ecological validity compared to real-time interaction; cannot definitively determine participants' internal experiences beyond self-report; no a priori sample size calculation; competence-based social status might not be representative of all forms of social status
