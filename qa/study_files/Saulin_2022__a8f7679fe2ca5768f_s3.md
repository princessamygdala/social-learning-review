## Computational level
- **study_focus:** Prosocial learning; multi-motive prosocial decision-making (empathy + reciprocity)
- **study_focus_short:** Prosocial learning
- **learning_mode_description:** - Learning mode: Learning from motive induction (empathy, reciprocity, or both) about prosocial decision process     - Learning from:       - Source type (social): other (confederate partners)       - Source content (social): outcome (pain observation for empathy; helping decision for reciprocity) — **joint** in multi-motive condition     - Learning about:       - Target type (social): other (confederate partner)       - Target content (social): action/policy (prosocial vs. egoistic allocation preferences)
- **task_description:** After separate or combined induction of empathy (observing partner's pain) and reciprocity (partner forgoing money to save participant from pain) toward different confederates, participants performed a binary dictator game allocating points prosocially or egoistically. - **players:** Single agent (participant), multi-target (4 confederates representing empathy partner, reciprocity partner, multi-motive partner, baseline partner)
- **n_players:** multi-target (3+)
- **partner_type:** confederate
- **stimuli:** Pain stimulation observation, helping decisions from partner, binary point distributions (dictator game with advantageous inequality)
- **method:** fMRI
- **main_result:** - More prosocial choices in multi-motive vs. reciprocity condition (z-ratio = 3.49, P = .003); multi-motive vs. empathy comparable (z-ratio = .56, P = .94)   - DDM: z-parameter (initial prosocial bias) increased in multi-motive vs. reciprocity (p = 93.55%, plausible T(32) = 3.66, P < .001); percent change $\Delta$z = 6.40 $\pm$ 1.21%, T(32) = 5.36, P < .001   - a-parameter: relative increase in multi-motive vs. reciprocity ($\Delta$a = 9.77 $\pm$ 4.36%, T(32) = 2.28, P = .03)   - v-parameter: unchanged between conditions   - Neural: bilateral dorsal striatum tracked individual $\Delta$z (right: x = 30, y = 2, z = -2, P(FWE) = .001; left: x = -28, y = -9, z = 1, P(FWE) = .003)   - Empathy dominance could not explain multi-motive effect ($\beta$ = -0.20, P = .42)
