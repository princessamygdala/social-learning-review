## Computational level
- **study_focus:** Observational threat learning -- how observers acquire threat associations (CS-US contingencies) by watching a demonstrator's defensive responses, and how brain-to-brain coupling (BtBC) and perceived social status modulate this learning.
- **study_focus_short:** Observational threat learning -- how observers acquire threat associations
- **learning_mode_description:** - Learning mode: Learning threat associations by observing another person's aversive reactions to conditioned stimuli   - Learning from:     - Source type (social): other (demonstrator)     - Source content (social): action/policy (demonstrator's defensive behaviors / facial expressions / thumb movements in response to shock)   - Learning about:     - Target type (non-social): world (stimulus-threat contingency)     - Target content (non-social): state (which stimulus predicts shock / threat value of CS)
- **task_description:** Observers watched video recordings of a demonstrator undergoing Pavlovian threat conditioning (CS+ probabilistically paired with electric shock at 62.5%) while MEG was recorded from both. Observers then completed a direct test in which they were exposed to the CSs alone, with learning assessed via SCR and pupillometry.
- **task_paradigm:** Observational learning task
- **players:** Single agent (observer participant), dyadic (demonstrator; sequential, not simultaneous interaction). N=60 observers, N=3 demonstrators. Each demonstrator paired with ~20 observers. Half assigned to high-status condition, half to low-status.
- **n_players:** network (5+)
- **partner_type:** human (live)
- **stimuli:** White geometric shapes (triangle, rectangle, circle, pentagon) on black background as CSs; video recordings of demonstrators' responses; electric nerve stimulation (US, 200 microseconds pulse to right wrist of demonstrator).
- **method:** MEG / behavioural
- **method_full:** MEG (sequential imaging of demonstrator-observer dyads) + behavioural (SCR, pupillometry, eye tracking) + computational modeling
- **main_result:** - Main Results:   - Successful observational learning: CS+ > CS- on SCR (beta = 0.39, SE = 0.07, t = 5.97, P < 0.001)   - Successful observational learning: CS+ > CS- on pupil response (beta = 0.45, SE = 0.09, t = 4.85, P < 0.001)   - Model-derived initial value: CS type x social status interaction (beta = -0.04, SE = 0.003, t = -15.76); larger V0 for CS+LS > CS-LS compared to CS+HS > CS-HS   - Learning rate: CS type x social status interaction (beta = -0.20, SE = 0.01, t = -27.90); faster CS+ learning in LS group, reversed pattern in HS group   - Sensor-level BtBC: CS+ vs CS- significant cluster (P = 0.001) in delta/theta (1-8 Hz), 0.6-5.5 s   - Source-level BtBC in LS group: lINS_rINS, lvmPFC_rINS, rvmPFC_rINS, lDLPFC_rINS predicted differential pupil response (all r > 0.56, PFDR < 0.05)   - NMF cluster 1 BtBC in CS+LS predicted differential SCR (r = 0.44, P = 0.02) and differential learning rate (r = 0.47, P = 0.01)   - SVR prediction: BtBC predicted learning outcome starting ~4.7 s post CS onset (r > 0.49, MAE < 0.28)   - Eye-to-eye coupling: CS+ > CS- in LS group (beta = 0.54, SE = 0.15, t = 3.83, P < 0.001)   - BtBC at lDLPFC_rINS correlated with empathic concern in LS group (r = 0.41, P = 0.03)

- **concerns:** - Preprint (not yet peer-reviewed at time of posting) - Very small demonstrator sample (N=3), creating nested structure where ~20 observers share the same demonstrator - No sample size justification other than matching previous publications - Model comparison metric not explicitly named - Exact fitted parameter values not reported (only interaction patterns) - Sequential imaging means demonstrator and observer never truly interact in real time
