## Computational level
- **study_focus:** Trust learning / cooperation learning — how trust develops dynamically during iterated games of strategic interaction (Prisoner's Dilemma and Chicken Game) and mediates transfer of learning between games.
- **study_focus_short:** Trust learning / cooperation learning
- **learning_mode_description:** - Learning mode: Learning from interaction outcomes with a partner about the partner's trustworthiness to guide cooperative strategy   - Learning from:     - Source type (social): other (computerized confederate agent playing a strategy)     - Source content (social): outcomes (joint payoff outcomes from cooperation/defection choices)   - Learning about:     - Target type (social): other (confederate agent)     - Target content (social): state (mental state; trustworthiness — reactive and proactive trust)
- **task_description:** Participants played two sequential 50-round games of strategic interaction (Prisoner's Dilemma and/or Chicken Game) with a computerized confederate agent that used either a Tit-for-Tat or Pavlov-Tit-for-Tat strategy with manipulated trustworthiness (high vs. low). On each round, both players chose to cooperate or defect, earning points based on the payoff matrix.
- **task_paradigm:** Prisoner's dilemma
- **players:** Single agent (participant), dyadic (computerized confederate agent)
- **n_players:** dyadic (2)
- **partner_type:** confederate
- **stimuli:** Abstract payoff matrices (2x2 games), binary choices (cooperate/defect), point feedback
- **method:** online / behavioural
- **method_full:** behavioural / online
- **main_result:** - Model with trust mechanism predicted human behavior better than five model variants without trust (r = 0.66, RMSD = 0.19 vs. best variant r = 0.50, RMSD = 0.24) - State trust was sensitive to confederate strategy (F(1,316) = 11.49, p < 0.05) and trustworthiness (F(1,316) = 73.182, p < 0.05) - State trust after game 1 predicted cooperation frequency in game 2 (R² = 0.10, β = 0.05, p < 0.01) - Original model (trust + trust-invest) outperformed reactive-only model (r = 0.66 vs. r = 0.61; Steiger's Z_H = 13.86, p < 0.001) - No deep transfer effects from PD to CG confirmed in human data (matching model predictions) - Trait trust was not a significant predictor of cooperation behavior (p > 0.05)
- **effect_size:** - Model-human correlation: r = 0.66 (overall), RMSD = 0.19 - State trust predicting cooperation: R² = 0.10, β = 0.05 - Steiger's Z_H = 13.86 (original vs. reactive model) - Strategy effect on state trust: F(1,316) = 11.49 - Trustworthiness effect on state trust: F(1,316) = 73.182

## Quality
- **sample_size:** N = 320 (176 male, 144 female; M_age = 36.62, SD_age = 10.67); recruited from Amazon Mechanical Turk; 20 participants per condition (16 conditions)
- **population_category:** healthy adults
- **population_age_range:** 
- **ecological_validity:** Low ecological validity. Participants played abstract 2x2 matrix games with computerized confederate agents using predetermined strategies, not real human partners. The strategic interaction is highly simplified compared to real-world trust-building scenarios. Authors acknowledge this limitation and suggest future work with more complex agents and non-verbal cues.
- **eligibility_flag:** The "social agent" is an automated computerized confederate agent using predetermined strategies (T4T, PT4T), not a real human partner — FLAG as automated social agent. Additionally, the computational model is an ACT-R cognitive architecture model that was fit to a prior dataset and tested for predictive validity here; it is not a standard computational model fit to individual-level data in this study. The model is not fit to data in this paper — it generates a priori predictions. This is borderline for "uses computational modeling" in the standard sense (model comparison is done at the group level via correlation/RMSD, not individual-level parameter estimation).
- **concerns:** - The model was originally fit to data from Juvina et al. (2013) and only tested for predictive validity here — no individual-level fitting was performed in this study - Confederate agents used simple predetermined strategies, limiting ecological validity and generalizability to human-human interaction - Authors acknowledge the model performed poorly in conditions starting with Chicken Game, possibly due to performance-based incentives differing from the original study - Exact parameter values for the ACT-R model are not reported in this paper (deferred to Juvina et al., 2015) - Number of free parameters is never explicitly stated - The model variants comparison is limited — authors acknowledge they have not exhausted all possible simpler models - Overall model-human correlation (r = 0.66) is notably lower than original fit (r = 0.87)
- **limitations_reported:** Others have noted differences in behavioral outcomes between humans playing in pairs with one another and humans playing with deterministic strategies"; "the games was shortened from 200 to 50 rounds, which limited the experience of the participant with the confederate agent"; "the participants were paid for performance, whereas in the original study they were paid a fixed amount"; "We do not claim to have exhausted the full set of simpler models that could explain the empirical data"; ecological validity limited — model does not account for non-verbal cues or facial expressions
- **limitations_categorized:** limited ecological validity; task simplicity (computerized agents vs. human partners); generalizability concerns (performance incentives differed from original study); incomplete model comparison space; reduced trial count from original paradigm; no individual-level fitting
