## Computational level
- **study_focus:** Neurochemical (genetic) mechanisms of social vs. individual learning; whether dopamine- and serotonin-related genetic polymorphisms (DAT, COMT, SERT) differentially affect social versus individual learning.
- **study_focus_short:** Neurochemical (genetic) mechanisms of social vs. individual learning
- **learning_mode_description:** - Learning mode: Learning from own reward outcomes and from others' choices about reward contingencies in a volatile environment   - Learning from:     - Source type (non-social): self       - Source content (non-social): outcome (reward feedback -- blue/green indicator)     - Source type (social): group (previous participants' choices)       - Source content (social): action/policy (group's most popular choice represented by orange frame)   - Learning about:     - Target type (non-social): world       - Target content (non-social): state (reward probability associated with blue/green shapes)     - Target type (social): group       - Target content (social): state (accuracy/reliability of group advice)
- **task_description:** Participants completed an online probabilistic social learning task choosing between blue and green shapes for points, with an orange frame indicating the social advice (most popular prior participants' choice); probabilities for both reward and social advice accuracy varied across stable and volatile phases.
- **task_paradigm:** Volatility task (Behrens)
- **players:** Single agent (participant), multi-target (group of 4 previous participants, simulated)
- **n_players:** small group (3-4)
- **partner_type:** human (live)
- **stimuli:** Abstract shapes (blue/green), orange frame (social cue), blue/green feedback indicator, reward progress bar
- **method:** behavioural (online) + genetic analysis (DAT, SERT, COMT genotyping)
- **main_result:** - Significant main effect of information type on alpha: alpha_individual > alpha_social (F(1,567) = 256.521, eta_p^2 = 0.311, BF_incl > 100) - SERT: significant volatility x SERT interaction on alpha (F(2,567) = 4.535, eta_p^2 = 0.016); S/L carriers showed lower alpha in volatile vs. stable phases - SERT: main effect on zeta (F(2,567) = 6.326, eta_p^2 = 0.022, BF_incl = 7.681); s-allele carriers showed higher social weighting - SERT: NO genotype x information type interaction (F(2,567) = 1.019, eta_p^2 = 0.004, BF_excl = 18.891) - DAT: significant genotype x information interaction (F(2,567) = 3.571, eta_p^2 = 0.012, BF_incl = 2.686); 9/9 carriers showed larger difference between alpha_individual and alpha_social - DAT: NO genotype x information x volatility interaction (BF_excl = 16.950) - COMT: no main or interaction effects - S/L SERT carriers showed highest accuracy (mean = 0.626) vs. S/S (0.613; d not reported) -- difference significant - Higher alpha in stable vs. volatile phases overall (d = 0.086)
- **effect_size:** eta_p^2 = 0.311 (information type main effect); eta_p^2 = 0.016 (SERT x volatility); eta_p^2 = 0.022 (SERT on zeta); eta_p^2 = 0.012 (DAT x information); d = 0.086 (stable vs. volatile alpha)
