## Computational level
- **study_focus:** Strategic learning / competitive interaction learning — how reinforcement-based and belief-based learning rules jointly drive strategic behavior in competitive games.
- **study_focus_short:** Strategic learning / competitive interaction learning
- **learning_mode_description:** - Learning mode: Learning from one's own payoffs and opponent's observed actions about the value of available strategies in a competitive game.   - Learning from:     - Source type (non-social): self       - Source content (non-social): outcome (received payoffs)     - Source type (social): other (anonymous opponent)       - Source content (social): action/policy (observed opponent investment choices)   - Learning about:     - Target type (non-social): world (action values / strategy values)       - Target content (non-social): action/policy (optimal investment strategy)     - Target type (social): other (anonymous opponent)       - Target content (social): action/policy (anticipated opponent strategies / beliefs about opponent's future actions)
- **task_description:** Participants played a competitive Patent Race game in which Strong (endowment=5) and Weak (endowment=4) players were randomly matched each round and chose investment amounts; the higher investor won a prize of 10 units, while both lost their investment. Participants completed 160 rounds across two fMRI sessions.
- **task_paradigm:** Auction task
- **players:** Single agent (participant), multi-target (anonymous opponents from a population pool; random matching each round)
- **n_players:** multi-target (3+)
- **partner_type:** human (live)
- **stimuli:** Abstract investment game display showing endowments, opponent endowment, potential prize; numerical feedback on opponent's choice and payoff outcome
- **method:** fMRI
- **method_full:** fMRI
- **main_result:** - Main Results:   - Hybrid EWA model fit behavior significantly better than pure RL or pure belief learning models (BIC and out-of-sample log-likelihood comparisons; paired t-test P ≤ 0.01)   - RL prediction error correlated with bilateral ventral striatum activity (R: T = 6.01; L: T = 5.87)   - Belief prediction error correlated with bilateral ventral striatum (R: T = 7.22; L: T = 5.90) and rACC/mPFC (T = 4.96)   - rACC activity uniquely correlated with belief (not RL) prediction error; belief PE betas > RL PE betas in rACC (paired t-test P < 0.05)   - Individual differences in behavioral engagement of belief learning (δ_i) correlated with rACC neural response to belief PE (Pearson ρ = 0.66, P < 0.01)   - Correlation between RL and belief prediction errors was low (Pearson ρ ≈ 0.28)

- **ecological_validity:** Stylized competitive game with anonymous random matching reduces ecological validity but provides clean strategic learning environment.
