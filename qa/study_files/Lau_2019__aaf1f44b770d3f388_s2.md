## Computational level
- **study_focus:** Social group inference via latent structure learning -- how people accumulate information about others' political preferences to infer group boundaries beyond dyadic similarity
- **study_focus_short:** Social group inference via latent structure learning -- how people accumulate
- **learning_mode_description:** - Learning mode: Learning latent social group structures from observing others' political preferences and one's own, and using these to guide choice and trait attribution     - Learning from:       - Source type (social): other (Agents A, B, C -- preferences observed via feedback)       - Source content (social): action/policy (political issue preferences: yes/no stances)     - Learning about:       - Target type (social): group (latent group structure -- which agents belong together)       - Target content (social): state (mental state; group membership / coalition structure)
- **task_description:** Participants stated their own political issue preferences and received feedback on three agents' preferences across 8 trials per block. At the end of each block, participants chose between two agents' mystery policy positions. Agent C's agreement with the participant was manipulated to create or break latent group structures.
- **task_paradigm:** Social network learning
- **players:** Single agent (participant), multi-target (3 agents per block: A, B, C)
- **n_players:** triadic (3)
- **partner_type:** human (live)
- **stimuli:** Text-based political issue positions (yes/no), face photographs from Chicago Face Database, colored mystery boxes
- **method:** behavioural / online (Amazon Mechanical Turk)
- **main_result:** - Exp 1: Participants more likely to choose Agent B after high C-agreement blocks (53.24%) vs. low C-agreement (44.97%) (b = 0.348, z = 2.05, p = .041)   - Exp 2: Replication with high-consensus issues (55.16% vs. 43.27%; b = 0.482, z = 2.952, p = .003)   - Exp 3: Replication of choice effect (52.54% vs. 43.87%; b = 0.352, z = 2.78, p = .005) + trait attribution: Agent B rated higher on morality/competence/likability after high C-agreement blocks (mean diff = 0.208, p < .001) and lower after low C-agreement blocks (mean diff = -0.107, p = .013); interaction F(1, 2881.8) = 26.14, p < .001   - Exp 4: Effect persists despite countervailing explicit team labels (45.95% vs. 34.35%; b = 0.486, z = 3.99, p < .001)
- **effect_size:** Exp 1: b = 0.348 (logistic); Exp 2: b = 0.482; Exp 3: b = 0.352 (choice), F(1, 2881.8) = 26.14 (trait attribution interaction); Exp 4: b = 0.486
