## Computational level
- **study_focus:** Convention learning / social coordination learning — how individuals learn partner-specific and community-level linguistic conventions through repeated referential communication.
- **study_focus_short:** Convention learning / social coordination learning
- **learning_mode_description:** - Learning mode: Learning from a partner's communicative behavior (utterance choices and referent selections) about the partner's system of meaning (lexicon), and generalizing those expectations across partners to form community-level conventions.   - Learning from:     - Source type (social): other (communication partner)     - Source content (social): action/policy (utterance production and referent selection behavior)   - Learning about:     - Target type (social): other (partner) / group (community)     - Target content (social): state (mental state; partner's lexical/semantic system of meaning)
- **task_description:** In a repeated reference game, participants are assigned speaker and listener roles and shown an array of novel objects (e.g., tangrams or abstract shapes). The speaker produces a referring expression (natural language or artificial label) to communicate the identity of a highlighted target to the listener, who selects an object; both receive feedback. Partners swap across blocks and across a network of interactants.
- **task_paradigm:** Coordination game
- **players:** Multi-agent (dyads within small fully connected networks of 4), symmetric (roles swap each block). Experiment 1: N=92 participants in 23 networks of 4. Experiment 2: N=278 participants in 127 dyads.
- **n_players:** network (5+)
- **partner_type:** human (live)
- **stimuli:** Abstract tangram figures (Experiment 1); hierarchically structured colored shapes with artificial nonsense-word labels (Experiment 2).
- **method:** online / behavioural
- **method_full:** behavioural / online
- **main_result:** - Main Results:   - Speakers reduced utterance length significantly over successive interactions with the same partner (b = -0.19, t(34) = -9.88, p < .001) [Exp 1]   - Utterance length increased significantly at partner swaps (b = 0.43, t(22) = 4.4, p < .001) [Exp 1]   - Initial descriptions shortened with successive new partners, indicating generalization (b = -0.2, t(516.5) = -6.07, p < .001) [Exp 1]   - Across-pair alignment increased over partner swaps (interaction of pair type x partner number: b = -0.85, z = -5.69, p < .001) [Exp 1]   - Communicative accuracy improved over time across all context conditions (z = 14.4, p < .001) [Exp 2]   - Effective vocabulary size differed by context condition: coarse m = 5.5, mixed m = 7.9, fine m = 8.3 (t(95) = 13.2, p < .001 coarse vs. mixed; t(95) = 13.3, p < .001 coarse vs. fine) [Exp 2]   - Participants in coarse condition reported significantly more general terms (m = 2.3) vs. mixed (m = 0.47) and fine (m = 0.04) (t(91.8) = 8.8, p < .001; t(90.2) = 9.2, p < .001) [Exp 2]

## Quality
- **sample_size:** Experiment 1: N = 92 participants (23 fully connected networks of 4). Experiment 2: N = 278 participants (127 dyads: 36 coarse, 38 fine, 53 mixed). Simulations: 1,000 trajectories (Sim 1.1, 1.2), 48 networks (Sim 2.1), 400 trajectories (Sim 3.1). All participants recruited from Amazon Mechanical Turk.
- **population_category:** healthy adults
- **population_age_range:** 
- **ecological_validity:** Uses interactive online reference games with real-time communication, which captures genuine social coordination dynamics. However, artificial lab tasks with novel stimuli (tangrams, nonsense words) limit ecological validity relative to real-world language use. Networks are small (4 people) and interactions short. Artificial-language tasks (Exp 2) further reduce naturalism.
- **eligibility_flag:** This paper is primarily a computational modeling/theory paper with behavioral experiments. The CHAI model is a computational model applied to human behavioral data in a social learning context (convention formation over time). Learning occurs over time (repeated interactions across multiple partners). All inclusion criteria are met. However, the model is evaluated via qualitative simulation-to-data comparison rather than formal model fitting to trial-level data — this is a notable limitation for the systematic review's algorithmic-level analysis.
- **concerns:** - No formal quantitative model fitting to individual participant data; model is evaluated by qualitative comparison of simulation outputs to aggregate behavioral patterns. - No formal model comparison metric (BIC, AIC, etc.) — models compared on basis of which qualitative patterns they can/cannot produce. - Parameters are hand-set rather than fitted to data ($\alpha_S = \alpha_L = 4$ or $8$, $w_C = 0.24$, $\beta = 0.8$, $\lambda = 2$). - No parameter recovery or model recovery analyses. - Experiment 2 was preregistered but Experiment 1 was not explicitly noted as preregistered. - Effect sizes are only regression coefficients; no standardized effect sizes (d, r, etc.) reported.
- **limitations_reported:** The authors acknowledge: the model is computationally intractable and requires approximation for scaling; the simulations only consider simple two-word descriptions with homogeneous uncertainty while real descriptions are more heterogeneous; the model does not account for incremental language processing within a single utterance; memory mechanisms are simplified (simple decay rather than working memory vs. long-term memory distinctions); the model does not capture richer sources of social feedback (e.g., backchannels, repair, gestures); the model does not address how perceptual or conceptual representations themselves are adapted through interaction; network sizes are small and may not scale to real community sizes; children's difficulties in reference games suggest additional developmental constraints not captured; the approach does not specify which exact representations are adapted at the process level.
- **limitations_categorized:** computational intractability; task simplicity; limited ecological validity; simplified memory model; limited social feedback modeling; scalability concerns; no process-level specification; limited developmental generalizability
