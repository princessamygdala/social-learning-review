## Computational level
- **study_focus:** Neural correlates of social group structure learning -- separate brain areas track dyadic similarity vs. latent group structure during social learning
- **study_focus_short:** Neural correlates of social group structure learning -- separate brain areas
- **learning_mode_description:** - Learning mode: Learning latent social group structures and dyadic similarity from observing others' political preferences, and identifying which brain regions track each process     - Learning from:       - Source type (social): other (Agents A, B, C -- political preference feedback)       - Source content (social): action/policy (political issue preferences)     - Learning about:       - Target type (social): group (latent group structure) **joint** with other (dyadic similarity to each agent)       - Target content (social): state (mental state; group membership / coalition structure)
- **task_description:** Participants stated their own political issue preferences and learned about three agents' preferences over 8 trials per run during fMRI scanning. At the end of each run, they chose to align with one of two agents on a mystery issue. Model-based parametric modulators indexed trial-by-trial dyadic similarity and latent group structure updating.
- **task_paradigm:** Social network learning
- **players:** Single agent (participant), multi-target (3 agents per run: A, B, C)
- **n_players:** triadic (3)
- **partner_type:** human (live)
- **stimuli:** Text-based political issue positions (yes/no), face photographs from Chicago Face Database, grey mystery boxes
- **method:** fMRI
- **main_result:** - pgACC tracked trial-by-trial dyadic similarity updating (cluster size = 327 voxels, peak: 18, 48, 0)   - rAI/IFG tracked trial-by-trial latent group structure updating (cluster size = 696 voxels, peak: 34, 16, -10)   - rAI signal improved prediction of ally-choice behavior above model predictions (chi-squared(1) = 5.312, p = 0.021)   - pgACC signal did not improve prediction of ally-choice behavior (chi-squared(1) = 1.526, p = 0.217)   - Agent B agreement positively predicted ally-choice (b = 2.325, z = 4.099, p < 0.001)   - Agent C agreement also positively predicted ally-choice (b = 1.322, z = 2.633, p = 0.008)   - Significant negative B x C interaction (b = -0.307, z = -2.588, p = 0.010)   - 44.7% overlap between rAI cluster and non-social cluster updating ROI from Tomov et al. (2018)
