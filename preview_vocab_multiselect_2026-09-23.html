Pick one or several on each side, for instance self and other as the source and state as the target content, and the studies that match appear below. Within one box the selections are alternatives; across boxes they narrow each other. The small number on each chip is the result you would get by adding that chip to the current selection, so it drops when the chip narrows the set and grows when it adds an alternative on a side you have already used.

What the preview decides that the live figure does not

  • Several selections in one box mean "either". Self and other selected as the source returns studies that learn from either, not studies that learn from both. Studies coded with two source types satisfy it twice over and appear once.
  • Selections in different boxes narrow each other. Source other with target content state returns only studies that have both.
  • An empty box means no constraint, so the page opens with all studies listed.
  • Counts are conditional. The number on a chip is the size of the result if you added it, given everything already selected, which is why the numbers change as you click.
  • Setting is a separate row rather than a chip on the wrapper, since the coded setting field takes one value per study.
